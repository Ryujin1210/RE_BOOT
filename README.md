**RE:BOOT**은 시니어 세대의 정신 건강 문제를 해결하기 위해 개발된 생성형 AI 기반 미술치료 서비스입니다.

노인복지시설의 한정된 예산과 전문 인력 부족 문제를 해결하기 위한 서비스로,
<br />
사용자는 AI 봇과 음성으로 대화하며 과거 경험을 회상하고,
<br />
이 대화를 바탕으로 AI가 맞춤형 도안을 실시간으로 생성합니다.
<br />
생성된 도안을 색칠하는 과정에서 다시 한번 AI와 대화하며 심리적 치유를 경험할 수 있습니다.
<br />

**RE:BOOT**은 미술활동 과정에서 사용자의 발화 내용과 심리 상태를 분석하여,
복지시설 상담사나 치료사가 빠르게 사용자를 이해하고 체계적으로 상담 데이터를 관리할 수 있도록 돕습니다.

## 🌟 주요 기능

- 음성 질문을 통한 회상 기법으로 도안 생성
- 대화형 미술치료 진행 (색칠하며 AI봇과 대화)
- 작품 기록 및 심리 상태 분석 (사용 색상, 발화 단어 수, 긍정/부정 단어 분석 등)
- 상담 데이터 체계적 관리 및 상담 효율성 향상
- 미술치료 대상 확대 및 다양한 미술활동 컨텐츠 확장 가능
